## What's changed

### New

- **Disk Drive menu.** The game window's Switch Floppy menu is now Disk Drive, and its **Select Disk...** puts any disc image on your computer in the drive. **Hide Disk Drive Menu** in a game's Settings takes the menu away, and it's ticked by default for a game with one disc.
- **A3000 speed and a real drive's speed for every game.** Each game's Settings can run it at the speed of an A3000's 8 MHz ARM2 and load its floppies at a real drive's speed, where before only games added on My Games could.

### Changed

- **Escape in full screen** leaves full screen and frees the mouse.
- **CRT-Royale-Pi** no longer darkens the edges of the picture.
- **Downloads are made by PiArcBoot itself**, not by the system's curl.
- Links in the launcher show a hand pointer.

### Fixed

- **Chocks Away Compendium** loads and plays. ADFS keeps a 4K directory cache and no file buffers, which leaves the module area room for the modules the game loads, and the ROM is ROO311 v1.0.9, which gives the start-up banner's memory back before a floppy's boot file runs.
- Installing with the curl or irm command in a terminal now returns the terminal to its prompt once PiArcBoot starts.
- Disc images with an & in their names, as Bug Hunter & Moondash's have, are found on JASPP's release pages.
