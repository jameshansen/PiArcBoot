## What's in it

The first release. PiArcBoot installs Acorn Archimedes games from JASPP and boots each one straight into the game, in a window of its own, with no ROM to find and no emulator to set up.

- **110 JASPP games**, each installed from JASPP with its icon, and started behind a splash screen with the keys it needs pressed for you. All 110 reach their own screens from their first disc.
- **Classics**, a second tab of free games: Acorn Arcade's freeware releases and the games in RISC OS Open's package sources that run on RISC OS 3.11, each made into floppy images when it is installed.
- **Your own disc images**: JFD, ADF, ADL and HFE images, or a zip of them, become games with an icon from a sprite on the disc.
- **Copy protection as the disc has it.** A JFD's sector places, CRC errors, sizes and numbers reach the floppy controller as on the real disc, so the games' own disc checks pass.
- **Saves are kept** in a file beside each disc image, which itself is never changed. Each disc can be made read only.
- **The machine** is ArcEm, set up as an Archimedes with a 25 MHz ARM3 and 4MB, or as an A5000 with its 82C711 for Botkiller 2 and Speedball 2 [RPC], which come on 1.6MB discs. The ROM is ROO311 v1.0.3.
- **Three downloads**: 64-bit Raspberry Pi OS, Linux PCs and Windows. On Linux a guided installer adds PiArcBoot to the Games menu and the desktop.

## Known issues

- APD disc images aren't read.
- Games that run inside the RISC OS desktop aren't listed yet.
- ArcElite takes 39 seconds of machine time to load from its floppy.
- Joysticks aren't supported.
