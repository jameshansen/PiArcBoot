## Install

- **Raspberry Pi:** download `PiArcBoot.tar.gz` below and extract it, open the `PiArcBoot` folder, double-click `install.sh` and choose Execute, then choose **Install**. It needs 64-bit Raspberry Pi OS 13 (trixie) or newer.
- **Linux PC:** `PiArcBoot-Linux-x86-64.tar.gz` installs the same way, on a 64-bit desktop as new as Ubuntu 24.04 or Debian 13.
- **Windows:** extract `PiArcBoot-Windows.zip` anywhere and run `piarcboot.exe` in the `PiArcBoot` folder.
