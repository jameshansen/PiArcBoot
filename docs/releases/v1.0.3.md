## What's changed

### New

- **Hard disc installs.** The nine JASPP games that came with a hard disc installer install onto a folder the machine reads directly, so they start from it with no discs to swap: Black Angel, Break 147 & Superpool, Carnage Inc, Drop Ship, The Exotic Adventures of Sylvia Layne, Haunted House, Raw Power, Saloon Cars Deluxe and Stunt Racer 2000. The files each installer copies are taken straight off the disc images, as a list in `presets/` says, and a copy is kept so the game starts from a fresh one if its folder is ever removed. Their discs added with Add Game get the same.
- **Windows Only.** A game that plays in the RISC OS desktop can be shown cropped to its windows, leaving out the icon bar and the desktop around them, and the picture follows them as they open, close and move. Windows Only in the Game menu turns it on or off for any game, your own included, and PiArcBoot remembers the choice. A small window of the game's is never blown up past the window's scale, and the pointer goes where yours is over the picture.
- **Three more JASPP games.** Mah-Jong Patience, Premier Manager and SimCity play in the desktop, and are listed now that they can be shown cropped to their windows. The list has 113 games.
- **Desktop games start in 256 colours.** A game shown Windows Only starts on a 640 by 512 desktop in 256 colours, as the Classics do. Haunted House and Premier Manager, which asked for a 256 colour mode, start straight into play, and SimCity's question about changing to Mode 12 is answered No for it.
- **Straight into play.** Black Angel starts in the MODE 15 it asks for and goes straight to its space dock. Break 147 & Superpool, Drop Ship and Saloon Cars Deluxe have their request for the original disc 1 answered for them, as disc 1 is always in the drive.
- **Archives in Add Game.** Add Game takes zip, Spark and ArcFS archives of RISC OS applications. Their files go on floppy images, or in a folder the machine reads directly when they're too big for floppies or need the support pack, and the game starts from the application named after the archive, or its biggest.
- **Icons.** Star Fighter 3000 and the PackMan games in Classics show their own icons before they are installed, and `piarcboot.exe` has PiArcBoot's icon on Windows.

### Fixed

- Star Fighter 3000's music and sound effects play in full. A load that steps its base by a register now steps it by that register's value from before the load, as the ARM2 and ARM3 do, even when the load overwrites it, and its sample player relies on that.
- A disc image shorter than 800K that ends at the end of a cylinder keeps the cylinders after it unformatted, as on the original disc. STARCH's protection checks for that and starts now.
- Disc images added with Add Game whose root directory isn't named `$`, as on some E format discs, start their application instead of trying to boot the disc.
- After a game had been played from the launcher on Linux, the launcher could wait on the game before finishing a download. Games now run apart from it.

### Inside

- The ROM is ROO311 v1.0.6, whose HostLink module reports where the windows on the screen are.
- Presets take `mode=` (a screen mode for a game that plays in the desktop), `crop=1` (Windows Only by default), `match=` (disc images added by hand that are one of a preset's games) and `<game>.install` (the files a hard disc installer copies). `presets/README.md` describes them.
- `piarcboot ls <image>` lists every file on a disc image, and `piarcboot extract <file> <folder>` writes out the files in an archive or disc image, for writing presets.
- `tests/installers.sh` runs each game's real installer in the emulator, worked by a script in `tests/installers/`, and checks it copies the same files as the game's list.

A game installed before its preset was added gets it when it is installed again, so reinstall the nine hard disc games to have them start from their own folder.
