## What's changed

### New

- **Save states.** Every game has 3 save slots in a new Saves menu, each holding the whole machine with a screenshot of the moment it was saved. One slot, ticked as Selected for Auto Save, is written every 30 seconds of play on a thread of its own, so the game doesn't pause for it. Restoring a slot makes it the one Auto Save writes, and a slot holding a save from an earlier session isn't written over until it is restored, saved to or chosen. What a game wrote to a floppy goes back to how it was too, while files in a game's own folder stay as they are.
- **The selector.** A game with saves starts on its 3 slots side by side, with their screenshots and when each was saved, and nothing runs until one is picked. Continue restores a slot, New Game starts afresh in an empty one, and Erase takes a save away after asking. Open Selector in the Saves menu brings it up during a game, which waits behind it. A restored game loads over its own picture, blurred, which clears to sharp before the game carries on from it.
- **The sound comes up gently.** Whenever a game starts, after a boot, a new game or a restore, its sound rises from nothing to full over a second.
- **Search.** A search field over the launcher's tabs shows just the games whose title or line of information match, and each tab says how many in red.
- **Save Snapshot.** The Game menu saves the picture as you see it as a PNG in your Pictures folder, named after the game and the time.
- **GAMES.md** lists every game in the JASPP and Classics tabs, with its year, publisher, discs and how it installs.

### Changed

- **Ctrl+Alt shortcuts.** Full screen is Ctrl+Alt+Enter and a disc is Ctrl+Alt and its number, so Alt, Enter and every other key belong to the game. Star Fighter 3000's thrust and fire are Alt and Enter, which used to switch to full screen. While the game has the mouse it has the keyboard too, Alt+F4 and Alt+Tab included, and Escape gives both back.
- **The Game menu** opens with Send ESC and ends with Close, and Windows Only is now called Crop to Window.
- **The pointer moves as far across the picture as the mouse does in any screen mode**, as HostLink now says how many OS units make a pixel.

### Fixed

- Star Fighter 3000's menus take each click where the pointer is. Clicking Play Game pressed Quit Menu, as the games modes it plays in were the wrong height in OS units.
- Ctrl+Alt and a number reaches the game when the game has no disc of that number. Alt and a number never reached games without discs, Star Fighter 3000 among them.

### Inside

- The ROM is ROO311 v1.0.7, whose games modes are 1280 by 1920 OS units and whose HostLink gives each mode's eigen factors.
- A save state is every part of the machine one after another, each with its length, squeezed by zlib, with the screenshot in front. One made with another version of PiArcBoot or its ROM isn't restored, and the game carries on as it was.
- `tests/savestate.sh` saves a game's state partway through a test script and restores it in a second run, and both have to end as the same machine.

Save states made with this version may not restore in a later one whose ROM or machine has changed.
