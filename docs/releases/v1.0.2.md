## What's changed

### New

- **Star Fighter 3000 starts full screen.** It used to open in a desktop window. F12 still brings back the desktop window, and its menu still has Full screen.
- **Meteors starts full screen.** Escape is pressed for it as it starts, which puts it on the whole screen.
- **Puzzle** joins the Classics tab. It installs with ROO311's support pack, whose new `!Boot` gives it the `Choices:` path it stopped without.
- **Presets.** What PiArcBoot knows about particular Classics games is in `presets/`, which goes with each release beside the program, not in its code. A game can have files that Install adds to its own, such as a choices file, and settings: the support pack it needs, keys to press once it has started, or why a PackMan game is left out. `presets/README.md` describes them.

A game installed before its preset was added gets it when it is installed again, so reinstall Star Fighter 3000 to have it start full screen.

### Inside

- The ROM is ROO311 v1.0.5, and the support pack is its `toolbox.zip`, now with a `!Boot` holding a Choices folder.
