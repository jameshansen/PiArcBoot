## What's changed

### New

- **PiArcBoot for the Mac.** One application for Apple silicon and Intel Macs, built for macOS 10.13 or newer, in `PiArcBoot-macOS.zip`. The terminal command puts it in the Applications folder, and from the zip it's dragged there. Games are kept in `~/Library/Application Support/PiArcBoot`.
- On a Mac a game's menus are in the menu bar at the top of the screen, Select Disk and Add Game use the Mac's open dialog, and a game's shortcuts are applications of their own on the desktop and in `Applications/PiArcBoot Games`, which Launchpad shows. CRT-Royale-Pi and CRT-Pi run on the Mac's OpenGL.
