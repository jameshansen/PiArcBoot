## What's changed

### New

- **Star Fighter 3000** in Classics. Release 3.21, free from its own site, needs the nested Window Manager and the Toolbox and is too big for a floppy, so it installs into a folder the machine reads through ArcEm's HostFS, with ROO311's support pack beside it. The pack's Window Manager goes in an extension ROM, which RISC OS takes up at power on in place of the ROM's own.
- **Installed games come first** in each section of the Classics tab, under Installed and Available headings.

### Fixes

- The desktop no longer shows before a game. A game that starts from an application is started by ROO311's HostLink module, and the splash screen stays up until HostLink reports that the game has taken the screen, opened an error box to ask for a disc, or started as a task in the desktop. Lemmings goes from the splash straight to black.
- Classics games start on a 640 by 512 desktop in 256 colours, where it had been 16.
- The Windows version opens no console window.
- The default icon, for a disc with no sprite to make one from, is a floppy disc.
- The captured mouse notice reads "Press ESC to release mouse".
- A game window has only the system's own menu bar, and a game with one disc has no Switch Floppy menu.

### Inside

- The ROM is ROO311 v1.0.4, with HostLink 1.01.
- ArcEm's HostFS and extension ROM code are built in, for the games that have a support pack. Every other game gets the same machine as before.
