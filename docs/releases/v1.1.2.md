## What's changed

### New

- **Settings menu.** The game window's menu bar has Settings, with the game's own settings: Capture Mouse on Click, Slower Mode (A3000 Speed), Real Drive Speed, Hide Disk Drive Menu and Crop to Desktop Window. A change there takes effect straight away and is kept for that game.
- **A game that quits closes its window.** Quitting to the RISC OS desktop, from a game's own menu or by closing a desktop game's windows, closes PiArcBoot's window too.

### Changed

- **Crop to Desktop Window**, which was Crop to Window in the Game menu, is in the Settings menu, and every game's Settings box has it.
- The Settings box's options are named as the menu has them: Capture Mouse on Click and Slower Mode (A3000 Speed).
- A game shown cropped to its windows has its window follow them as they change size, and come back to the desktop's size when they close.

### Fixed

- Open Selector no longer shows a tick.
- The game window's menus have room for a game with nine disks and auto switch points.
- Select Disk waits until the game has finished booting.
