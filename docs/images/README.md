# System icons

`os-raspberrypi.png`, `os-windows.png` and `os-linux.png` mark the downloads for each system in the release notes. `tools/mkosicons.py` makes them from each system's own logo, the way PiArcBoot makes a game's icon from its sprite.

- The Raspberry Pi logo is a trademark of Raspberry Pi Ltd.
- The Windows logo is a trademark of Microsoft Corporation.
- Tux, the Linux penguin, is by Larry Ewing, drawn with The GIMP, and may be used and changed with that acknowledgement.

Each logo is used only to say which system a download is for.
