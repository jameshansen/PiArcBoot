# Freely distributable games

The games the launcher's Classics tab installs, kept here as they were downloaded, so they stay available if the sites they came from go. They are not part of PiArcBoot or its releases: the launcher downloads a game from here when it is installed, and from the site it came from if this copy can't be reached.

Each folder is one source, with `SOURCE.txt` saying where the files came from, when, and the terms they are distributed under. Each game remains the work of its authors and publishers.

| Folder | Source |
| --- | --- |
| `acornarcade` | [Acorn Arcade's free games](http://www.acornarcade.com/articles/Free_games/index879.html) |
| `asylum.acornarcade` | [The Asylum and Oddball site](http://asylum.acornarcade.com/) |
| `support-packs` | [ROO311's releases](https://github.com/jameshansen/ROO311/releases): the modules a game that needs more than RISC OS 3.11 gets beside it |
